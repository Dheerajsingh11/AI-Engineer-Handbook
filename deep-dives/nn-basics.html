Neural Network Basics

Why stacking linear layers with a non-linearity between them can approximate anything. Section 01 BeginnerStart from zero

Assumed knowledge

The chain rule and gradient descent from Topic 1.4, and matrix multiplication from Topic 1.1. If you have those, everything here follows.

A neural network is a stack of the logistic regression you built in Topic 2.3, with one crucial addition. That framing makes it much less mysterious than the brain metaphors usually applied to it.

The problem a single layer cannot solve

Logistic regression draws a straight line between two classes. Some problems have no such line. The standard example is XOR:

XOR — no straight line separates the classes
x₁x₂Output
000
011

110

Plot those four points. The two 1s sit on one diagonal, the two 0s on the other. No straight line separates them — and this single observation nearly killed neural network research for fifteen years after Minsky and Papert pointed it out in 1969.

The solution is a hidden layer: first transform the inputs into a new representation where the problem is linearly separable, then draw the line there. The network learns both the transformation and the line at the same time.

Why the non-linearity is non-negotiable

Suppose you stack two linear layers with nothing between them: y = W2(W1x). Matrix multiplication is associative, so this equals (W2W1)x = Wx for a single matrix W. A hundred stacked linear layers collapse into one. The depth buys nothing whatsoever.

Insert a non-linear function between them and the collapse is impossible. That is the entire reason activation functions exist, and it is worth being able to state in one sentence at an interview.

The words, in plain English
Neuron / unit
One weighted sum followed by an activation. That is all — the biological name is historical.
Layer
A group of neurons computed together, as one matrix multiply.
Hidden layer
Any layer between input and output. "Hidden" only because you do not directly observe its values.
Activation function
The non-linear function applied after each weighted sum.
Forward pass
Running data through the network to get a prediction.
Backward pass
Computing how every weight should change. Backpropagation.
Epoch
One complete pass over the training data.
Batch
The group of examples processed together before one weight update.

Section 02 IntermediateThe anatomy of a layer

One layer a[l]  =  f( W[l]a[l−1] + b[l] ) Multiply by a weight matrix, add a bias, apply a non-linear function. Repeat. The bias matters more than it looks — without it every layer's output is forced through the origin, which restricts what the network can represent.

Section 03 AdvancedBuild a network from scratch

Backpropagation for a whole layer, derived by hand, then written in NumPy. Once this works, PyTorch stops being a black box.

Backward pass through one layer
  1. Forward: Z = XW + b,   A = f(Z) X is (batch, in), W is (in, out), so Z and A are (batch, out).
  2. Given ∂L/∂A, first go through the activation: ∂L/∂Z = ∂L/∂A ⊙ f′(Z) Element-wise, since f is applied element-wise.
  3. ∂L/∂W = XT · ∂L/∂Z Shapes force this: (in,batch)×(batch,out) = (in,out), matching W. Checking shapes is the fastest way to get these right.
  4. ∂L/∂b = Σbatch ∂L/∂Z The bias is added to every row, so its gradient is the sum over the batch.
  5. ∂L/∂X = ∂L/∂Z · WT This is what gets passed to the previous layer. The recursion that makes deep networks trainable.  ■
PythonA complete neural network, NumPy only
import numpy as np

class Dense:
    def __init__(self, n_in, n_out, activation="relu", rng=None):
        rng = rng or np.random.default_rng(0)
        # He init for ReLU: var = 2/n_in keeps activation variance
        # stable across layers. Xavier (1/n_in) suits tanh/sigmoid.
        scale = np.sqrt(2.0 / n_in) if activation == "relu" else np.sqrt(1.0 / n_in)
        self.W = rng.normal(0, scale, (n_in, n_out))
        self.b = np.zeros(n_out)
        self.activation = activation

    def forward(self, X):
        self.X = X                                # cached for the backward pass
        self.Z = X @ self.W + self.b
        if   self.activation == "relu":    self.A = np.maximum(0, self.Z)
        elif self.activation == "sigmoid": self.A = 1 / (1 + np.exp(-np.clip(self.Z, -500, 500)))
        else:                              self.A = self.Z
        return self.A

    def backward(self, dA):
        if   self.activation == "relu":    dZ = dA * (self.Z > 0)
        elif self.activation == "sigmoid": dZ = dA * self.A * (1 - self.A)
        else:                              dZ = dA

        n = len(self.X)
        self.dW = self.X.T @ dZ / n               # line (3)
        self.db = dZ.sum(axis=0) / n              # line (4)
        return dZ @ self.W.T                      # line (5)

    def step(self, lr):
        self.W -= lr * self.dW
        self.b -= lr * self.db


class Network:
    def __init__(self, layers):
        self.layers = layers

    def forward(self, X):
        for layer in self.layers:
            X = layer.forward(X)
        return X

    def backward(self, dA):
        for layer in reversed(self.layers):       # reverse order matters
            dA = layer.backward(dA)

    def step(self, lr):
        for layer in self.layers:
            layer.step(lr)


def bce_loss(y_true, y_pred, eps=1e-9):
    y_pred = np.clip(y_pred, eps, 1 - eps)        # never log(0)
    loss = -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))
    # Gradient of BCE w.r.t. the prediction
    grad = (y_pred - y_true) / (y_pred * (1 - y_pred)) / len(y_true)
    return loss, grad


# --- solve XOR: the problem one layer cannot do -------------------
X = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = np.array([[0.], [1.], [1.], [0.]])

rng = np.random.default_rng(1)
net = Network([Dense(2, 8, "relu", rng),
               Dense(8, 1, "sigmoid", rng)])

for epoch in range(5000):
    pred = net.forward(X)
    loss, grad = bce_loss(y, pred)
    net.backward(grad)
    net.step(lr=0.5)
    if epoch % 1000 == 0:
        print(f"epoch {epoch:5d}  loss {loss:.5f}")

print(net.forward(X).round(3))
# [[0.008] [0.992] [0.991] [0.010]]  -- XOR solved

# Remove the hidden layer and it cannot get below ~0.69 loss,
# which is exactly the loss of always guessing 0.5. Try it.

Section 04 AdvancedInitialisation, normalisation and regularisation

Why initialisation decides whether training works

Set all weights to zero and every neuron in a layer computes the identical thing, receives the identical gradient, and stays identical forever. The layer has one effective neuron regardless of its width. This is the symmetry problem, and it is why weights must start random.

But the scale of that randomness matters just as much. Too large and activations grow layer by layer until they saturate or overflow; too small and the signal decays to nothing before reaching the output.

Principled initialisation Xavier / Glorot: Var(W) = 2nin + nout  He: Var(W) = 2nin Both are chosen so the variance of activations stays roughly constant from layer to layer. He initialisation has the extra factor of 2 because ReLU zeroes out half its inputs, halving the variance — so you compensate up front. Use He with ReLU-family activations, Xavier with tanh or sigmoid. Frameworks default sensibly; know this so you can diagnose a network that will not train.

Why transformers use LayerNorm rather than BatchNorm

BatchNorm normalises each feature using statistics computed across the batch. That creates two problems for language: sequences have different lengths, so the batch statistics are computed over padding as much as content; and inference often runs with batch size 1, where batch statistics are meaningless and you must fall back to stored running averages. LayerNorm normalises across the features of each token independently, so it is identical whether the batch holds one example or a thousand. For sequence models this is decisive.

Section 05 ProfessionalWhat networks can and cannot do

The universal approximation theorem says a network with one hidden layer can approximate any continuous function to arbitrary accuracy — given enough units. This is quoted often and misunderstood almost as often.

What the theorem does not say
  • It says such a network exists. It says nothing about whether gradient descent can find it.
  • "Enough units" may mean exponentially many. Depth is far more parameter-efficient than width, which is why real networks are deep rather than wide.
  • It covers approximation on the training domain. It promises nothing at all about generalisation to new inputs — and generalisation is the only thing that matters.

The practical reading: capacity is rarely your bottleneck. Data quality, the loss you chose, and your evaluation discipline are.

Architecture families and what they encode
ArchitectureBuilt-in assumptionSuited to
MLP / fully connectedNone — every input relates to every otherTabular data; the feed-forward block inside a transformer
CNNLocality and translation invarianceImages, audio spectrograms, some time series
RNN / LSTMSequential order, fixed-size stateSequences — largely superseded by transformers
TransformerAny token may relate to any otherText, and now nearly everything else
GNNExplicit graph structureMolecules, social networks, knowledge graphs (§4.8)

The pattern worth noticing: each architecture bakes in an assumption about the data. The right assumption means you need far less data to learn. The transformer's assumption is unusually weak — "anything may relate to anything" — which is why it needs enormous data and why it generalises across so many domains once it has it.

Section 06 ProfessionalExercises

Do these — roughly one weekend
  1. Type in the Dense and Network classes and solve XOR. Then delete the hidden layer and confirm the loss stalls at ln 2 ≈ 0.693.
  2. Set all weights to zero instead of random. Watch the network fail completely, and confirm every hidden unit has identical weights afterwards.
  3. Multiply the He initialisation scale by 50. Print activation magnitudes layer by layer and watch them explode.
  4. Replace ReLU with sigmoid in a six-layer network. Print the gradient norm at each layer and watch it vanish toward the input.
  5. Train on MNIST with your own code. A two-layer MLP should exceed 97% test accuracy; getting there yourself is a genuinely satisfying milestone.
  6. Add dropout to your Dense class. Remember it must be active during training and disabled at inference — forgetting that is a classic bug.
  7. Gradient-check every layer: perturb one weight by h, measure the loss change, compare against your analytic gradient. They should match to about six decimal places.
